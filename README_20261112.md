# Todo List Web Application

Spring BootとThymeleafを用いた、シンプルなタスク管理Webアプリケーションです。
CRUD操作（登録・取得・変更・削除）とエラー防止機能の実装を行っています。

---

## 技術スタック (Tech Stack)

- **Backend:** Java 17 (17.0.17), Spring Boot 3.3.5, Spring Data JPA
- **Frontend:** HTML, CSS, Thymeleaf, JavaScript (Confirm Dialog / Alert)
- **Database:** MySQL (XAMPP)
- **Development Environment:** Eclipse (Pleiades), Apache Tomcat (Spring Boot内蔵)

---

## 主な機能 (Features)

1. **一覧表示**
   - データベースに格納されている自動採番されたID（4桁表示）、タスク名、期限日、未完了/完了（□/☑）の4項目が表示されます。
   - 変更項目を選択できるラジオボタン、期限日による判定、削除ボタンも表示されます。
2. **タスクの登録**
   - タスク名と期限日を入力して新規登録されます。
   - 新規登録された項目は一覧表示の一番下に追加され、表示されます。
3. **タスク名・期限日の変更**
   - 一覧から対象のラジオボタンを選択し、新しい内容を入力して変更ボタンを押すことで、データを更新できます。
4. **タスクの削除**
   - 一覧から対象の削除ボタンを選択し、確認ダイアログで確認後、データを削除できます。
5. **期限日による判定機能**
   - 本日の日付とタスクの期限日を比較し、「期限前」「今日まで」「オーバー」のステータスバッジを自動で色分け表示します。
6. **タスクの状態管理（完了 / 未完了）**
   - チェックボタンをクリックすることで、未完了（□）と完了（✓）を切り替え可能です。完了したタスクには動的にCSSクラス（is-completed）が付与され、取り消し線が引かれる仕様です。
7. **エラー防止機能：削除確認**
   - 削除ボタンを押した際にJavaScriptの確認ダイアログを表示し、誤操作による削除を防止します。
8. **エラー防止機能：「null」確認**
   - 削除及びタスクの状態管理において、不正なリクエストやデータのズレ（すでに別の場所で消されている等）から意図せぬIDが入力された場合も「null」チェックを行いエラー防止を徹底しています。
9. **エラー防止機能：空欄入力防止**
   - タスクの登録フォームでは、HTML側で「required」を追記することで空欄入力を防げます。
   - タスク名・期限日の変更フォームでは、いったん空欄入力のまま処理を行い、エラーメッセージの表示を行うことで空欄入力を防げます。

## 操作説明（How to use this app）

1. **タスクの登録**
   - 「入力フォーム」内のタスク名と期限日を入力して「入力」ボタンを押すと新規登録されます。
   - 新規登録された項目は一覧表示の一番下に追加され、表示されます。
2. **タスク名・期限日の変更**
   - ToDoリスト一覧から対象のラジオボタンを選択し、「変更フォーム」のタスク名または期限日を入力して「変更」ボタンを押すことで、データを更新できます。
3. **タスクの削除**
   - ToDoリスト一覧から対象の削除ボタン（右端ゴミ箱アイコン）を選択し、確認ダイアログで確認後、データを削除できます。
4. **タスクの状態管理（完了 / 未完了）**
   - チェックボタンをクリックすることで、未完了（□）と完了（✓）を切り替え可能です。完了（✓）時は該当タスクに取り消し線が引かれます。

## アーキテクチャ・ファイル構成 (Architecture)

MVCモデルに則り、責務を明確に分離して設計しています。

- **Entity (`Todo.java`)**: データベースの `Todos` テーブルと1対1でマッピングされるエンティティクラス。JPQLによる名前付きクエリを定義。
- **DAO (`MyDAO.java` / `TodoService.java`)**: 共通のCRUD操作インターフェースを実装し、データベースの登録・取得・更新・削除処理を担当。
- **Controller (`TodoController.java`)**: リクエストを受け付け、サービス層へ処理を委譲、画面（Model）へデータを渡す。
- **View (`todoList.html`)**: Thymeleafを用いた動的なHTMLテンプレート。
- **Static Assets (`todo_style.css`, ファビコン・アイコン)**: スタイルシートと画像リソース。
